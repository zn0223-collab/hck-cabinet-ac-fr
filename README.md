# Comment choisir un climatiseur de armoire pour enveloppes industrielles

Guide pratique de dimensionnement pour armoires électriques, télécom, batteries et cabines.

Au-delà de ~40°C d'ambiance, le ventilateur ne suffit plus. Le **circuit fermé** (compresseur, IP55) maintient 25–35°C et exclut poussière/humidité.

## Dimensionnement
- Petit (<2 m3): **3000 W**
- Moyen (2–4 m3): **5000 W**
- Grand/conteneur (>4 m3): **7500 W**

## Ce qui compte
- IP55 pour extérieur et industrie
- Fonctionne **de -40°C à +55°C**
- R410A + microcanal (~30% plus efficace)
- RS485/Modbus à distance
- dès 52 dB, sans outil
